The remaining 22 are ONE root cause, and that is the finding worth recording. They are
five method-not-found on ProvDrbg (instantiate, uninstantiate, reseed, generate), seven
mismatched types, seven expected-function-found-i32, and three argument errors. The staged
file calls the four cached virtual functions as METHODS -- (*drbg).instantiate(...) -- where
the authority stores them as function pointers, so the compiler resolves them against a
field whose type is not a function pointer; every one of the seventeen type errors is a
call site of those four. Representing them as fn-pointer fields and calling them as such
should close all 22, and that is the next single edit rather than seventeen.
