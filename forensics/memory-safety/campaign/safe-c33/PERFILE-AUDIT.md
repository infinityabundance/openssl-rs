## 5. Residual obligation register

These obligations remain after the current contracts. They are not repaired by a SAFETY comment.

1. **Provider/application callback reentrancy** — every `EvpMd` function pointer (`newctx`, `dinit`, `dupdate`, `dfinal`, `dsqueeze`, `digest`, `freectx`, `copyctx`, `dupctx`, `get_params`, `set_ctx_params`, `get_ctx_params`, `gettable_params`, `settable_ctx_params`, `gettable_ctx_params`, `cleanup`, `init`, `update`, `final_`, `copy`, `md_ctrl`) and the signature callbacks in `do_sigver_init` are caller/provider-controlled. The code often reads context or method fields after the callback returns; a callback that frees or mutates the object is not guarded. Affected groups include the rows for `evp_md_from_algorithm`, `cleanup_old_md_data`, `evp_md_ctx_clear_digest`, `evp_md_ctx_free_algctx`, `evp_md_init_internal`, `evp_md_init_legacy`, `evp_md_final_legacy`, all `EVP_Digest*` provider paths, and the `do_sigver_init`/`sigver_*` family.
2. **Raw owning member pointers not mediated by a slot** — `EvpMd::type_name` (owned `*mut c_char`), `EvpMd::prov` (raw provider reference), `EvpMdCtx::md_data` (owned legacy block), `EvpMdCtx::fetched_digest` (owned method reference), `EvpMdCtx::pctx` (owned key context), `EvpMdCtx::algctx` (provider-owned opaque context), and the borrowed `digest`/`reqdigest` pointers. `cleanup_old_md_data`, `evp_md_ctx_clear_digest`, `EVP_MD_CTX_copy_ex`, `evp_md_ctx_copy_legacy`, and the destructor bodies reconstruct ownership by hand.
3. **Caller-asserted buffer extents and lengths** — `EVP_DigestUpdate`/`SignUpdate`/`VerifyUpdate` (`data`/`count`), `EVP_DigestFinal*`/`Squeeze` (`md`/`size`), `EVP_Digest`/`EVP_Q_digest`, `EVP_DigestSign*`/`EVP_DigestVerify*` (`tbs`, `sig`, `siglen`), `EVP_MD_CTX_ctrl` (`p1`/`p2`, including the `9999` fallback and negative `p1` cast to `usize`), and every `OSSL_PARAM` array. No group checks these extents; `RES_BUF` marks them.
4. **Aliasing and ownership in the copy paths** — `EVP_MD_CTX_copy_ex` and `evp_md_ctx_copy_legacy` call `ptr::copy_nonoverlapping(in_, out, 1)` without checking `out != in`; the legacy arm copies `algctx` and `fetched_digest` by value without NULLing or taking a reference. `EVP_MD_meth_dup` shallow-copies `type_name`/`prov`/`description` and then reuses the duplicate as if it owned them. These are `UNATTRIBUTED` for the raw-copy groups.
5. **Type-erased table data** — `set_legacy_nid` and `do_all_md_fn` cast `OBJ_NAME.data` to `EvpMd` based on the table's type argument; the data word is not type-tagged in this module.
6. **Static mutation** — `EVP_md_null()` returns the address of the immutable `N_MD`; `EVP_MD_meth_set_*` and `EVP_MD_up_ref`/`EVP_MD_free` do not reject `EVP_ORIG_GLOBAL` before some writes/reads. A C caller that casts away `const` can reach a write to static storage. The `StaticMd` `Sync` claim is a caller obligation, not a type-enforced one.
7. **Destructor implementer obligations** — `CtxDestroy::destroy_body` for `EvpMd` and `EvpMdCtx` is invoked by a safe `Drop`. The contract that it releases each member exactly once, never the enclosing block, and is valid for the zeroed state is asserted by the impl, not checked by the owner.
8. **Refcount/lifetime caller obligations** — `EVP_MD_up_ref`/`EVP_MD_free` assume a live object and a correct reference count; `EVP_MD_CTX_free` assumes allocator provenance and no double-free; `EVP_MD_CTX_get1_md` returns a legacy static as an owned pointer without a real reference.

## 8. What would make this audit `INDEPENDENTLY_CHECKED`
