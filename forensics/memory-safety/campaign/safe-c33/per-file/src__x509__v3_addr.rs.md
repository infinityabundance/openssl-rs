## 7. What would make this audit `INDEPENDENTLY_CHECKED`

For each group, an independent reviewer would need: the exact source and build identity (including the candidate binary, compiler, target, feature set and optimisation profile); a contract witness for every precondition (the exported C declaration and its OpenSSL API contract, an in-file caller, or an item-layer invariant); a runtime/static check that fires on a deliberate violation; and a written disposition of every residual. The minimum additional controls for this file are:

- a hostile C-caller court for the 54 exported groups (NULL, dangling, aliased, overlong and wrongly-typed stacks/values), including `INT_MAX`/`INT_MIN` for every length and `afi` outside 1/2;
- a reentrant `verify_cb` harness that, on its first invocation, clears `verify_cb` and frees the chain or the current certificate, covering both `X509v3_addr_validate_path` and `X509v3_addr_validate_resource_set`;
- an ASan/guard-page court for the ASN.1 bit-string and `addressFamily` fields with a hand-built `length`/`data` mismatch, covering `get_afi`, `addr_expand`, `i2r_address`, `ip_address_family_cmp` and `i2r_IPAddrBlocks`;
- an allocator witness plus double-free/foreign-pointer negative controls for all four `_free` groups, the `make_*` failure paths, the canonize merge and the `v2i` `CRYPTO_strdup`/`pop_free` paths;
- a BIO-method callback harness for the `i2r_*` printers, and a comparator negative control for the four sort sites (`is_canonical`, `canonize`, `subset`, `ip_address_or_ranges_canonize`);
- a differential d2i/i2d court with truncated, overlong and malformed DER for all four item groups.

Absent those, every group remains `ESTABLISHED`, `CONTRACTED` or `UNATTRIBUTED`, and the file remains not `SAFETY_DISCHARGED`.
